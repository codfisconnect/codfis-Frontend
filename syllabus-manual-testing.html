Training Tracks / Manual Software Testing

Manual Software Testing & QA Fundamentals

Build a solid foundation in software quality engineering: SDLC & STLC, test plan creation, test case design, defect tracking with Jira, API testing in Postman, and database verification.

Curriculum Outline

Core Module Breakdown

Module 01 Weeks 1–2

Software Fundamentals, SDLC & Agile Methodologies

Understanding software architectures, Waterfall vs Agile Scrum models, sprint ceremonies, user stories, acceptance criteria, and QA's role in agile teams.

Module 02 Weeks 3–4

STLC & Test Design Techniques

Software Testing Life Cycle stages, Requirement Traceability Matrix (RTM), Equivalence Partitioning (EP), Boundary Value Analysis (BVA), and Decision Table testing.

Module 03 Weeks 5–6

Test Execution, Defect Lifecycle & Jira

Writing reproducible defect reports, severity vs priority triage, logging and managing bugs in Jira, creating test execution cycles, and status dashboards.

Module 04 Weeks 7–8

Functional, Regression & Non-Functional Testing

Smoke, sanity, functional, regression, cross-browser compatibility, exploratory testing, and fundamental usability testing approaches.

Module 05 Weeks 9–10

API Testing Fundamentals with Postman

Client-server model, HTTP methods (GET, POST, PUT, DELETE), status codes, headers, payload validation, writing test scripts in Postman, and collection runs.

Module 06 Weeks 11–12

Database Verification (SQL) & Practical Project

Basic and intermediate SQL queries (SELECT, WHERE, JOINs, GROUP BY) for backend data validation. Complete end-to-end testing project with real defect logs.
