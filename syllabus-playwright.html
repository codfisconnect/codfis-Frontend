Training Tracks / Playwright Automation

Automation Testing with Playwright

Master Microsoft Playwright, modern TypeScript testing, Page Object Model design, API testing, and GitHub Actions CI pipelines through hands-on daily live engineering practice.

Curriculum Outline

12-Week Module Plan

Module 01 Week 1

Software Testing Fundamentals & Automation Concepts

Core testing principles, manual vs automation trade-offs, test case design techniques, test coverage mapping, and selector strategy foundations.

Module 02 Week 2

JavaScript & TypeScript Fundamentals for Test Automation

Variables, data types, arrow functions, async/await, promises, modules, and TypeScript type annotations needed for clean test scripting.

Module 03 Week 3

Playwright Setup, Browser Contexts & Locators

Environment configuration, npm setup, browser contexts, isolation, multi-browser execution, and modern user-facing locators (role, text, label).

Module 04 Week 4

Element Interaction, Auto-Waiting & Assertions

Clicking, filling, hovering, keyboard inputs, auto-waiting mechanisms, web-first assertions with expect(), and handling dynamic animations.

Module 05 Week 5

Test Organization, Fixtures & Custom Hooks

Test runner structure, test.describe, beforeEach/afterEach hooks, test isolation, and crafting reusable custom fixtures.

Module 06 Week 6

Complex UI Components, Iframes & File Uploads

Handling shadow DOM, nested iframes, modal dialogs, custom dropdowns, date pickers, file downloads, and multipart file uploads.

Module 07 Week 7

Page Object Model (POM) Framework Design

Architecting modular, maintainable POM classes, separation of locators and test actions, and reducing code duplication.

Module 08 Week 8

Test Data Management, Environments & Auth State

JSON/CSV test data providers, .env environment management, reusing browser authentication state (storageState) to speed up test execution.

Module 09 Week 9

API Testing & Network Interception with Playwright

APIRequestContext, validating JSON REST endpoints, HTTP status assertions, route mocking, and simulating network failures.

Module 10 Week 10

Debugging, Playwright Trace Viewer & Reporting

Playwright Inspector, recording test traces, video capture, screenshot comparisons, and generating HTML & Allure test reports.

Module 11 Week 11

Git, CI/CD Pipelines & Headless Execution

Git branching workflows, GitHub Actions workflow configuration, matrix test execution across Chromium, Firefox, WebKit, and artifact retention.

Module 12 Week 12

Framework Capstone Project & Technical Review

Build and publish a comprehensive end-to-end framework repository on GitHub. Code reviews, mock technical interview questions, and resume presentation.
